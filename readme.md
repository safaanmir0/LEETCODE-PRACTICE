About This Repository
This repository contains my solutions to problems from LeetCode, implemented using the C programming language.

As a BCA Artificial Intelligence and Machine Learning student, I am using this repository to strengthen my programming fundamentals, improve logical thinking, and develop problem-solving skills.

My goal is not simply to solve problems but to understand the logic behind them and learn how to implement solutions independently.
Objectives
- Strengthen C programming fundamentals.
- Improve logical thinking and analytical skills.
- Practise arrays, strings, functions, and loops.
- Learn different problem-solving techniques.
- Understand time and space complexity.
- Develop consistency through regular coding practice.
